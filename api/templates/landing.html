API Endpoints

RESTful endpoints with filtering, pagination, and full bilingual support

GET /api/v1/levels

All 12 education levels — Primary, Middle School, High School. Filter by category.

GET /api/v1/subjects

Academic subjects per level. Math, French, Arabic, Physics, SVT, Philosophy and more.

GET /api/v1/content

Educational content — courses, exercises, exams, corrections. Filter by type, level, difficulty.

GET /api/v1/search?q=

Full-text search with relevance scoring across all resources in French and Arabic.

GET /api/v1/stats

Comprehensive API statistics, data analytics, quality metrics, and usage data.

GET /health

Health check with data status, uptime, quality scores. Used by Railway for monitoring.

Quick Start

Start fetching Moroccan education data in seconds

Terminal 
# Get all education levels
curl "{{BASE_URL}}/api/v1/levels"

# Get Baccalaureate subjects
curl "{{BASE_URL}}/api/v1/subjects?level_id=lycee-2bac"

# Search for math content
curl "{{BASE_URL}}/api/v1/search?q=mathematiques"

# Get exams with filtering
curl "{{BASE_URL}}/api/v1/content?content_type=examen&level_id=lycee-2bac"
JavaScript (fetch) 
// Fetch Baccalaureate math content
const API = "{{BASE_URL}}/api/v1";

const res = await fetch(`${API}/content?subject_id=mathematiques-lycee-2bac`);
const { data, total } = await res.json();

console.log(`Found ${total} items`);
data.forEach(item => {
  console.log(`${item.title} (${item.content_type})`);
});
Python (requests) 
import requests

API = "{{BASE_URL}}/api/v1"

# Get all subjects for middle school
resp = requests.get(f"{API}/subjects", params={"level_id": "college-3"})
subjects = resp.json()["data"]

for s in subjects:
    print(f"{s['name']} — {s['name_ar']}")

# Search for physics exams
results = requests.get(f"{API}/search", params={"q": "physique examen"}).json()
